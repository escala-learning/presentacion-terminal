# Un curso desde la terminal · Scala Learning

Presentación para el equipo de Scala sobre cómo se produce un recurso educativo digital desde la
terminal con la cadena `/ova-*` del workspace, con dos cursos demo (Comunicación asertiva para
Andina y Finanzas personales para Posgrados Panamericana) maquetados hasta el tema 1, y hacia
dónde va con OVA Studio.

- `index.html`: el deck (flechas para avanzar, `N` notas del orador, `F` pantalla completa).
- `studio/`: OVA Studio, Propuesta B. Un recorrido con botones por la misma cadena; prototipo, no
  producto. La pantalla de fondo de la revisión es el tema 1 de la unidad demo de Andina.

Se publica en GitHub Pages en cada cambio en `main`.
